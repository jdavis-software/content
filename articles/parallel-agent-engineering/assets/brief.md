# Optional image / infographic production brief

Primary takeaway: parallel engineering works when isolated tasks converge through explicit validation, not because a larger agent count guarantees speed.

## GPT Image route
Use the host's available image-generation tool. Prefer a restrained editorial cover with separate workstreams converging into an integration gate. No fabricated logos, metrics, product screenshots, or performance badges. Preserve room for code-native title text. Record the actual provider/model when exposed; otherwise say model not exposed. Save the approved export under assets and update metadata, then validate. Do not use a paid API without a separately approved budget and authenticated connection. Do not put API keys in prompts or files.

## LinkedIn Animated Infographics route
Use the installed specialist workflow, evidence-first and static-first. Story: shared checkout collisions -> separate worktrees -> focused checks -> one integration review. Motion explains the flow, not an invented speed multiplier. Keep labels legible and provide a static fallback. Verify the export at feed size and respect reduced motion on the article site.

## Diagram route
workflow.mmd is the editable technical source. Render with an available Mermaid tool; verify output before replacing the original illustrative cover. A source file alone is not proof of a rendered diagram. Whimsical is optional, not required to read this article.
