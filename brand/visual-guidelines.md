# Visual direction

White editorial canvas, dark green-gray text, restrained forest-green accent. Broad margins, sharp type hierarchy, thin rules, and open layouts instead of nested cards. Dark mode uses the same semantic roles.

Cover graphics should explain a relationship, not decorate an unsupported claim. Preserve all official logo geometry when approved vendor assets are used; never fabricate logos. Technical labels remain editable. Diagrams have an accessible caption and source. No remote fonts, trackers, or runtime image service is needed by the site.

The pilot has a generated raster social card and homepage thumbnail with recorded provenance. Its original code-authored vector and Mermaid source are retained, and its interactive diagrams remain authored HTML/SVG. Do not represent generated imagery as a measured system graph or a Mermaid-rendered result.

Review at desktop and 390px mobile width. Prevent horizontal page overflow; code blocks and wide tables may scroll within their own container. Respect reduced motion and preserve keyboard focus. Social-platform exports require a supported raster image or media format; do not assume an SVG cover will work as a LinkedIn preview image.
